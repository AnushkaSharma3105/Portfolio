About the Project

GlowMuse Beauty is a modern front-end e-commerce platform designed for exploring and purchasing skincare and makeup products. It offers a smooth and visually appealing shopping experience with intuitive navigation and responsive design.

Key Features

  • Product browsing across multiple beauty categories
  • Add to cart and basic checkout flow
  • User-friendly login and registration interface
  • Responsive design for mobile and desktop

Tech Stack

HTML, CSS, JavaScript
